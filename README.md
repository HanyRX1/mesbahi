# MESBAHI — مِسباح

**عداد تسبيح إلكتروني من الكاميرا بالوقت الفعلي مع تفسير القرار الجزئي (XAI / SHAP).**

مشروع تخرج — قسم الذكاء الاصطناعي — بإشراف د. شادي الحكيمي.

---

## الفكرة (الخيار الأول: Explainable AI)

لكلّ مسلمٍ عملٌ محبوب: ذكر الله. بدل عدّاد ميكانيكي، تستخدم الكاميرا يدك نفسها:
**افتح يدك ثم اقبضها — كل قبضة كاملة = تسبيحة واحدة**. يلي العداد، وفي كل لحظة
يُفسَّر لك القرار بالضبط، فلا مجال للغمز ("لماذا عُدَّ 27؟").

المشروع تطبيق **واقعي** (حاجة يومية ملموسة)، يعمل **وقتاً حقيقياً** على كاميرا
الويب، ويطبّق مفاهيم XAI فعلياً عبر **SHAP** — لا مجرّد عرض نظري.

## لماذا هو "ذكي" ومُفسَّر (XAI)؟

| الطبقة | الدور |
|---|---|
| **MediaPipe Hands** | يخفّف 21 نقطة مفصلية من يدك المباشرة أمام الكاميرا |
| **Gradient Boosting (ذاتيّ التدريب)** | نموذج صغير مُدرَّب على تركيبات الأصابع يحول هندسة اليد إلى عدد أصابع مفتوحة (0–5) |
| **آلة حالة القبضة** | *فتح → قبض ثابت لعدد إطارات* = تسبيحة واحدة بدقة، بلا عدّ زائف من الاهتزاز |
| **SHAP (TreeExplainer)** | يوزع مساهمة كل إصبع في القرار لحظياً: بار أحمر = يزيد العدّ، بار أزرق = يقلّله |
| **حلقة 33** | عداد مسباح تقليدي: كل دورة 33 حبة، مع هدف قابل للضبط |

الي-Wيتش يجيب "**لماذا عُدَّ العداد هذا الرقم؟**" بوضوح: هذا هو جوهر XAI.

## التشغيل

```bash
pip install -r requirements.txt
python main.py              # كاميرا الويب الحقيقية
python main.py --simulate   # يد تجريبية بدون كاميرا (لعرض مضمون دائم)
python main.py --camera 1   # اختيار كاميرا أخرى
python main.py --goal 33    # تغيير الهدف (الافتراضي 100)
```

| المفتاح | الوظيفة |
|---|---|
| `Q` / `ESC` | خروج (وزر إغلاق النافذة ✕ يعمل أيضاً) |
| `R` | تصفير الجلسة |
| `S` | حفظ الجلسة إلى CSV |

> عند تعطُّل الكاميرا ينتقل التطبيق تلقائياً إلى وضع تجريبي (شعار ذهبي) —
> فلا يفشل العرض أمام اللجنة أبداً.

## الاختبارات

```bash
pytest tests/ -q      # 23 اختباراً: الميزات، العدّ، SHAP، آلة القبضة، الاستقرار
```

تغطي الاختبارات: استخراج الميزات على كل 32 تركيبة يد، ثبات المقياس، تفسير SHAP
لكل إصبع، الـ hysteresis، سلوك القبضة (فتح/قبض/احتفاظ/إعادة فتح)، و**بقاء تقدّم
التسبيح عند غياب اليد**.

## مخطط العمليات (Real-Time)

```
كاميرا ──► MediaPipe (21 مفصل) ──► ميزات الأصابع ──► GradientBoosting ──► عدد أصابع
                                            └────────────► SHAP: لماذا هذا القرار؟
آلة القبضة: اليد مفتوحة ──► سلّح  ──► قبضة ثابتة ──► +1 تسبيحة
```

كل إطار (~9 إطارات/ث على عتاد متواضع) يُرسم: العداد الكبير، حلقة 33، شريط
الهدف، حالة اليد (قبضة/مفتوحة)، وشريط SHAP الحيّ.

## الأسئلة المتوقعة في العرض (SHAP/XAI)

- **لماذا SHAP؟** كونه TreeExplainer — لحظي وسريع ومناسب للنموذج الشجري (GradientBoosting).
- **كيف نمنع العدّ الزائف؟** hysteresis + debounce إطارات متتالية + آلة حالة القبضة.
- **ماذا لو اختفت اليد؟** يُمسح مسلك الإيماءة فقط ويبقى تقدّم التسبيح.
- **ماذا لو فشلت الكاميرا؟** وضع تجريبي تلقائي يضمن استمرار العرض.
