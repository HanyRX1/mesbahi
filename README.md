# MESBAHI — مِسباح
**عداد استغفار ذكي من الكاميرا مع تفسير القرار (XAI).**

مشروع تخرج — قسم الذكاء الاصطناعي — بإشراف د. شادي الحكيمي.

---

## الفكرة
تفتح أصابعك أمام الكاميرا، وكل **إصبع تفتحه = استغفار واحد** يُضاف للعدّ.
تقوم الكاميرا بإحصاء الأصابع لحظياً، ثم يوضّح **SHAP** *لماذا* عُدَّ هذا الرقم
(أصابع تشرح نفسها أمامك) — تفسير قابل للفهم لكل إطار.

## لماذا هو "ذكي"؟
- تتبّع يدك عبر **MediaPipe** (21 نقطة مفصلية).
- **نموذج Gradient Boosting** مُدرَّب باكتشاف تركيبات الأصابع يحصي عدد الأصابع المفتوحة (0–5).
- **SHAP** يوزّع حصص كل إصبع على العدّ في الزمن الحقيقي:
  - بار أحمر → إصبع زاد العدّ، بار أزرق → إصبع قلّصه.
- عداد **33 حبة** لمُتابعة الحلقة، مع توهّج عند كل استغفار جديد.

## التشغيل
```bash
pip install -r requirements.txt
python main.py              # الكاميرا
python main.py --simulate   # بدون كاميرا (يد تجريبية) — للعرض
python main.py --camera 1   # كاميرا أخرى
```

| المفتاح | الوظيفة |
|---|---|
| `Q` / `ESC` | خروج |
| `R` | تصفير الجلسة |
| `S` | حفظ الجلسة إلى CSV |

## الاختبارات
```bash
pytest tests/ -q      # 15 اختباراً: الميزات، العدّ، SHAP، الـ hysteresis
```

## مخطط العمليات
```
كاميرا ──► MediaPipe (21 مفصل) ──► ميزات الأصابع (5 قيم
مقياس-ثابتة) ──► GradientBoosting ──► العدّ (0–5)
                                    └──► SHAP: لماذا هذا العدّ؟
```
